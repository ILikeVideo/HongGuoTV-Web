# 红果网页增强 0.2.5 安装说明

支持 Chrome、Edge 桌面版，最低 Chromium 138。本版本无需勾选“允许用户脚本”，不申请此权限。内置第一版界面和算法，动态业务及取流算法继续从后台取得已签名的新版本。

1. 解压 `hongguo-web-0.2.5.zip` 到固定目录。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 刷新 `https://hongguoduanju.com/`，顶部“榜单”与“下载”之间出现“我的”。保持“允许用户脚本”关闭即可；新版通常不再显示该选项。

所有播放使用官网原页面、原播放器和原控制栏。推荐原片和官网开放的剧集不重新取源；只有原锁定分集才使用动态手机端片源，图标显示为绿色解锁。选择这些分集不再弹出锁定集的 App 提示。暂停、进度、音量、全屏等由官网原控件处理，不插入另一套播放页面。

“我的”提供历史、收藏、点赞和预约。所有登录、验证码及退出均使用官网右上角入口，插件不提供登录表单。官网登录成功后，插件关联本机设备和手机号；已经登录时读取官网提供的号码，只有脱敏值时保留脱敏值。插件仅读取片单和云端进度，不主动修改历史、收藏、点赞或预约；官网自身行为由官网控制。

本机设备关联及可用会话保存在扩展存储中，不使用云同步，不发送给红果TV后台。官网退出后清除当前关联和会话。若官网会话不能读取手机片单，将明确提示，不提供另一套短信登录。卸载扩展会删除本机保存的账号资料。

“我的”为正常布局的顶部 Tab，没有返回按钮，通过顶部栏目或浏览器前后操作切换。封面自动兼容手机端HEIC格式。工具栏使用无文字标志，点击打开 `https://hongguoduanju.com/?tab=feed`；首页电视版按钮、下载右侧“红果TV电视版”Tab 和电视版二维码链接均在新标签页打开电视官网。

鼠标位于视频画布时，滚轮向下切下一集、向上切上一集；推荐页切下一部／上一部。侧栏、音量、进度、菜单内的滚动保留原行为。触控板缩放和横向滚动不接管。

扩展文件必须保留在原目录。账号资料页、动态业务、媒体处理、官网显示配置及取流算法自动检查更新；断网使用最后确认版本或内置首版。官网底层适配、宿主能力或权限改变时需更新 ZIP。

从旧版升级：将0.2.5解压覆盖原插件目录，在扩展管理页点击“重新加载”，再刷新已打开的官网页面；无需卸载，保留本机资料。0.2.4 起增加 scripting 权限，仅用于恢复红果官网中随包内置的桥接代码；不需要“允许用户脚本”。移除扩展会清除本机资料。

广告由红果TV后台“广告管理 → 插件广告”独立配置，默认关闭；所有广告均有标识和关闭入口。后台修改配置后通常一分钟内同步，失效配置两分钟内停止展示。配置或素材失败不阻断原视频。

服务器明确拒绝访问、作品下架或无可用片源时，沿用官网错误界面并提示原因，可刷新或重新选集重试。播放地址失效时自动刷新一次。浏览器是否能解码特定视频取决于浏览器及系统支持。
